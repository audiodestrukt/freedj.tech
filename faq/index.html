Questions

Answers to what people have been asking. freedj is two projects under one name: the hardware deck (ESP32-P4, 3D-printed) and freedj-3000, the software deck (OpenDeck DJ on iPad and iPhone, Raspberry Pi, Linux). Answers say which one they're about.

The basics

What is freedj?

Open-source DJ decks that behave like a CDJ: load a track, cue it, nudge it, loop it, and beat-sync with the other players in the booth over Pro DJ Link.

  • The hardware deck is a small standalone player: an ESP32-P4 board, a 4" touch screen, a real jog platter and a 3D-printed case. Plug in a USB stick, no laptop.
  • freedj-3000 is a software deck written in Rust. It ships as OpenDeck DJ on the App Store and runs on a Raspberry Pi 5 or a Linux PC.
Is it made by Pioneer, or connected to them?

No. freedj is an independent project with no connection to Pioneer DJ or AlphaTheta. None of their code is used. It talks to their players using the publicly documented Pro DJ Link protocol (thanks to Deep Symmetry's research), and reads rekordbox's USB export format.

Can I buy one?

Not right now. The hardware deck is a build-it-yourself project. The software deck is on the App Store as OpenDeck DJ, and free to build from source for the Pi and Linux.

When can I build the hardware deck?

The first release is being finished now: an off-the-shelf-parts version with a build guide, parts list and wiring table. There's no date yet. Everything so far is already public on GitHub if you want to start early, but expect it to change.

Devices

What does the software deck (freedj-3000 / OpenDeck DJ) run on?
  • iPad and iPhone: OpenDeck DJ on the App Store.
  • Raspberry Pi 5: 60 fps, about 0.6 of one core while playing with key lock. A Pi 4 runs it too, with less headroom.
  • Linux PCs with Vulkan graphics.

No Android, Windows or macOS build yet. Any screen works; the layout scales to the resolution.

Which board does the hardware deck use? Will other ESP32 boards work?

It's built for the Waveshare ESP32-P4-Module-DEV-KIT. That's the only board supported today.

  • Other ESP32-P4 boards (Guition, Espressif's own kits) could be ported: the chip is the same, but the screen, audio chip and pins differ. The case is also shaped around the Waveshare board.
  • Older ESP32s (ESP32, S3) don't have the speed or memory for this deck. There's a separate, experimental timecode-vinyl player for the ESP32-A1S audio board in the same repo.
Which screen?

A 4.0" 320×480 SPI touch screen (ST7796S with FT6336U touch, sold as the MSP4031 module or under brands like Hosyond). The case's window and screw bosses are made for it; check the hole spacing with calipers before printing, as clones vary. A larger DSI screen is planned.

Which controllers work?
  • Hardware deck: its own jog, CUE/PLAY and pitch fader, plus a Numark DJ2Go or a Pioneer XDJ-1000MK2 over USB (set the XDJ to USB MIDI control mode).
  • Software deck: any USB MIDI controller, mapped in a text file (controllers.toml) with LED feedback. Tested on a DJ2Go.

Want your controller supported? See contributing: a mapping is often an evening's work.

Does it have two decks, or a mixer?

Each freedj deck is one deck, like a CDJ: you pair it with another player and a mixer. A two-deck version with a built-in mixer (EQs down each side, one platter in the middle) is planned for the hardware deck.

Building one

What parts do I need?

For the first release, all off the shelf:

  • Waveshare ESP32-P4-Module-DEV-KIT and the 4" SPI touch screen;
  • an AS5600 magnetic angle sensor board with its diametric magnet (Ø4 × 2 mm);
  • two 608 skateboard bearings, and a steel ring for the platter's weight;
  • two 16 mm panel-mount push buttons and a slide potentiometer for pitch;
  • screws, M3 heat-set inserts, jumper wires, and the printed parts.

The full parts list comes with the build guide.

What 3D printer do I need?
  • Any FDM printer with a bed of about 256 mm or bigger prints the top shell in one piece. The deck is 160 × 185 mm.
  • Print the flat version first: it prints upside down with no supports. The angled version needs supports under the screen slope.
  • PLA or PETG both work for the case. PETG is tougher for the platter.
  • The jog shaft is a press fit into the bearings (8.1 mm printed, 8 mm bore). Printers vary, so print fit_gauge.stl first and pick the pin that fits snugly.
  • Small test pieces (jog_test_*) check the magnet gap before you commit to a full platter.
Do I need to design or order a circuit board?

No. The first release wires the buttons, pitch fader and sensor straight to the dev board with jumper wires, about nine wires in all. A small control board with lit buttons is designed and will come later as an optional upgrade.

How hard is it to build?

If you've flashed an ESP32 and soldered a header, you can build it. You'll press bearings, melt in heat-set inserts, glue in a magnet, crimp or solder a few wires, and flash the firmware from a computer over USB.

Can I change the case?

Yes. The case is parametric Python CAD (build123d). The size follows the jog and screen, and there are switches for angled or flat, the platter style and the button style. Remixes are welcome, under the hardware licence.

Music and the booth

What file formats play?
  • Hardware deck: WAV and MP3 (44.1 and 48 kHz). FLAC and AIFF are planned.
  • Software deck: MP3, FLAC, AAC, OGG, WAV and AIFF.
Does it work with my rekordbox USB stick?

Yes. Plug in a stick exported from rekordbox and the deck reads rekordbox's analysis: colour waveforms, beat grids, hot cues and memory cues.

  • Hardware deck: tracks are listed by BPM and file name for now. Playlists, titles and artists are next.
  • Software deck: also has its own beat detection, so tracks rekordbox never saw get a grid too.
Do I need rekordbox?

No. Both decks play plain music files from a USB stick or SD card. On the hardware deck, beat sync, quantize and beat loops need a beat grid, which today comes from rekordbox's analysis. The software deck analyses tracks itself.

Will it sync with CDJs in a club?

Both decks join a Pro DJ Link network with an Ethernet cable and take a player number.

  • Tested against a Pioneer XDJ-1000MK2. The software deck syncs both ways (it follows the master or becomes it) and browses the other players' media.
  • The hardware deck follows the tempo master. Becoming master is next.
  • CDJ-3000s speak the same sync protocol but haven't been tested yet. Own one? Ten minutes with this script would settle it.
Does it have key lock (master tempo)?

Yes, both. Change the tempo without changing the pitch.

Does it work with timecode vinyl?

That's a separate, experimental firmware for the ESP32-A1S audio board in the freedj-esp repo: put a control record on a turntable and play files in sync with it. It's in progress.

Other firmware

Can I run other firmware on the hardware deck?

The brain is a standard ESP32-P4 dev board, so you can flash anything that supports it. Other firmware won't know about the deck's jog sensor, buttons or screen unless it's written for them.

Can it run Mixxx, rekordbox, Serato or Engine DJ?

Not on the ESP32: those need a full computer. The Linux route is freedj-3000 on a Raspberry Pi, which is its own software deck.

Is the software deck the same code as the hardware deck?

No. They share ideas, file formats and the Pro DJ Link protocol, but the hardware deck is C++ for the ESP32 and the software deck is Rust for computers.

Licence and name

Is it free and open source?
  • Software and firmware: GPL. Read it, change it, share it.
  • Hardware (case CAD, circuit boards): CERN Open Hardware Licence, strongly reciprocal (CERN-OHL-S).

Both licences say the same thing: if you share or sell something built from freedj, you share its source under the same terms.

Can I build and sell my own?

The licences allow it, as long as you publish your changes under the same licence. But you can't use the freedj or audiodestrukt names or logos: they're trademarks, and they aren't covered by the open licences. Give your version its own name. "Based on freedj" is fine.

Is this legal?

freedj is a clean-room project: written from scratch, from public documentation and from watching how players behave on the network, with no Pioneer code or firmware. Pioneer, rekordbox, CDJ, XDJ and Pro DJ Link are trademarks of their owners and are named only to describe compatibility.

Contributing

How can I help?
  • Build one when the guide is out, and share photos. Report what was unclear.
  • Test with gear we don't have, especially CDJ-3000s and other Pro DJ Link players.
  • Map a controller you own.
  • Remix the case or design a platter.
  • Code: file formats, browsing, effects, ports to other boards.
How do I report a bug or suggest a feature?

Open an issue on GitHub: hardware deck or software deck. Say what you did, what you expected, and what happened, with your board or device.

How do I send code?

Fork the repo, make the change on a branch, and open a pull request. Small, focused pull requests get merged fastest. For anything big, open an issue first so we can agree on the approach. Contributions are accepted under the project's licence.

Where do I follow progress?

On the audiodestrukt blog, on Instagram, and in each repo's changelog.
